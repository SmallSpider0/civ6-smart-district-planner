# 智能区域规划器 · Windows 测试说明

版本 {{VERSION}}（{{DATE}}）。反馈时请写上这个版本号。

智能区域规划器是《文明6》的界面模组：选城市、点选想建的区域（必建或候选）、调产出权重，它在城市三环内找相邻加成最高的摆法，再一键打成带区域图标的地图钉。另有"选城址"和"多城"两个页签。开发和自测都在 macOS 上做，Windows 还没有测过，所以请你帮忙测。

压缩包里有四样东西：

- `SmartDistrictPlanner/`：模组本体；
- `TEST_GUIDE.md`：本说明；
- `INSTALL_AND_USE.md`：完整的安装、用法和 35 步验收清单；
- `REPORT.html`：交付报告，讲各功能怎么做、和 Auto Map Tacks Planner 等的对比结果、自测情况和截图。

两份说明都是纯文本，用记事本或任何编辑器打开即可。交付报告双击用浏览器打开，不需要联网（联网时字体更好看）。

## 1. 安装

1. **订阅依赖。**在 Steam 创意工坊订阅 Detailed Map Tacks（编号 2428969051）。Epic 版没有创意工坊，需要手动下载 DMT，放进下面的 Mods 文件夹。
2. **放进 Mods 文件夹。**把压缩包里的 `SmartDistrictPlanner` 文件夹整个放进：

   `文档\My Games\Sid Meier's Civilization VI\Mods\`

   - 放好后应该是 `Mods\SmartDistrictPlanner\SmartDistrictPlanner.modinfo`，不要多套一层文件夹。
   - 如果"文档"由 OneDrive 同步，实际位置在 `OneDrive\文档\My Games\…`。
   - 没有 `Mods` 文件夹就新建一个。
3. **启用。**启动游戏 → 主菜单"附加内容"，勾上 Detailed Map Tacks 和"智能区域规划器"，然后重启游戏。
4. **更新版本。**先删掉旧的 `SmartDistrictPlanner` 文件夹，再放新的。直接覆盖会留下新版已经删掉的文件。

## 2. 测试前

- **一局只开一个规划器。**关掉 Auto Map Tacks Planner、Empire Planner 等会自己打钉的模组，它们和本模组改的是同一个 DMT 函数，会互相把对方的钉当成邻居或删掉。改相邻规则、区域规则的模组也请关掉，否则结果和我们这边对不上。建议在"附加内容"里新建一个模组组，只开官方内容、DMT 和本模组。
- **新开一局，或者用存档的副本。**本模组不影响存档，打出的钉就是普通地图钉，停用模组后存档照样能读。多人游戏没测过，请先别在多人局里用。
- **打开 Lua 日志。**Steam 库 → 右键文明6 → 属性 → 启动选项，填 `-log`。日志在 `%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\Logs\Lua.log`，会跨启动追加。

## 3. 重点测什么

Mac 上已经用自动化测试验证过逻辑（游戏内 87 项、离线 73 项，三种规则集），也截了图。下面几项是 Mac 上测不到、或者 Windows 可能不一样的：

1. **界面布局。**请在 100% 和 150% 界面缩放、不同分辨率下各打开一次面板，看三个页签是否完整显示、有没有文字被截断或重叠。特别看：
   - 区域网格（每行三格）：名称和右侧的状态字（必建、候选、不建、自动）有没有重叠；英文界面下长名称会截断，悬停应显示全名；
   - 权重一行有没有挤出窗口：单城页 9 列（五种产出、食物、地貌、距离、住房），多城页 10 列（再加覆盖，列比别的行稍宽）；
   - 一行四个开关（计入占地、允许砍伐、替换旧钉、提醒钉）互不重叠；
   - "占人口名额的区域"标题行中间的"港口、商业中心分城"开关，与左边的标题、右边的"点一下：……"或"每城数量"不重叠；
   - 选了奇观后的标签是否换行正常，"添加奇观"下拉框能否打开。

   方便的话把游戏语言切到英文再看一遍。
2. **耗时。**Mac 上单城 8 个区域都必建、标准档约 0.3 秒出结果；从候选里挑时标准档约 1–2 秒（分帧）；多城 3 座城、每城 6 个区域、标准档约 7–8 秒（分几帧算，期间游戏不卡）。请记下你那边各档位的实际等待时间，以及面板上显示的"预计"。
3. **鼠标和键盘。**Mac 上的自动化工具不能点游戏窗口，这些只能靠人（上一版"区域格子点到必建后再点没反应"就是这样漏掉的）：启动栏按钮、页签、区域格子（点一下切换状态）、区域数量的箭头、奇观标签和"添加奇观"、勾选框、权重箭头、求解、继续优化、取消、方案行（点一行切换并预览）、打钉、撤销、Esc 关闭、Shift+L 开关面板、悬停提示。
4. **自动挑选和三套方案。**单城把学院设为必建、区域数量调到 4，看三套方案的区域组合是否不同、点方案行时地图预览是否跟着变；多城给每城数量 3，看每座城是否各挑了不同的区域。请记下耗时。
5. **这一版改的地方。**
   - 区域格子连续点：占人口名额的区域应是候选 → 必建 → 不建 → 候选；水渠、水坝这类是自动 → 必建 → 不建 → 自动。单城、多城两页都试。上一版必建、自动的格子点不动。
   - 多城页：城址钉（未建的市中心钉）的勾选框能取消，取消后它不参与规划、列表里标"不参与"。上一版取消无效。
   - 多城页勾"替换旧钉"再打钉：选城址页打的市中心钉应还在。上一版会被删掉。
   - 港口与商业中心分城（默认打开）：选一座沿海城，港口、商业中心都是候选、区域数量 ≥ 2，三套方案里同一座城不应同时有这两个；关掉开关再求解，可能会同时挑。两个都设为必建时照建，结果里有一行"港口与商业中心同城：灯塔不增加贸易路线"。
   - 社区：设为必建求解，结果行写"住房 +x（魅力 y）"。打开游戏的魅力透镜看那一格的魅力是否是 y，住房是否按 惊艳 6、迷人 5、普通 4、无吸引力 3、令人厌恶 2。再让工业区也必建，看工业区是否避开社区（挨着会让魅力 -1）。
   - 保护区：结果行写住房和"周边地块"产出。设为必建时周边产出计分；设为候选被挑中时只计住房，周边产出后面标"候选，不计分"。建成后（可用林苑、圣所）对照周围未开发地块多出的产出。
   - 娱乐中心和水上乐园：两个都设为必建，只放先列出的那个，另一个写"不能和……建在同一座城"；都设为候选时，三套方案里同一座城不会同时有。城里已建其一时，另一个格子置灰。
   - 必建区域抢同一块地（如沿海格很少的城同时必建港口和水上乐园）：应放下能放的，另一个写"没有剩余的空位"。上一版直接报错。
   - 区域放在农场、牧场上时，结果里多一行"占掉的改良设施 住房 -x"，对照城市详情里改良设施给的住房。
6. **完整清单。**按 `INSTALL_AND_USE.md` 里"验收测试"一节的 35 步走一遍。每一步写"通过"或"不通过 + 现象"即可。
