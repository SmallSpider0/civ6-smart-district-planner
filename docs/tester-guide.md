# 智能区域规划器 · Windows 测试说明

版本 {{VERSION}}（{{DATE}}）。反馈时请写上这个版本号。

智能区域规划器是《文明6》的界面模组：选城市、勾想建的区域、调产出权重，它在城市三环内找相邻加成最高的摆法，再一键打成带区域图标的地图钉。另有"选城址"和"多城"两个页签。开发和自测都在 macOS 上做，Windows 还没有测过，所以请你帮忙测。

压缩包里有三样东西：

- `SmartDistrictPlanner/`：模组本体；
- `TEST_GUIDE.md`：本说明；
- `INSTALL_AND_USE.md`：完整的安装、用法和 20 步验收清单。

两份说明都是纯文本，用记事本或任何编辑器打开即可。

## 1. 安装

1. **订阅依赖。**在 Steam 创意工坊订阅 Detailed Map Tacks（编号 2428969051）。Epic 版没有创意工坊，需要手动下载 DMT，放进下面的 Mods 文件夹。
2. **放进 Mods 文件夹。**把压缩包里的 `SmartDistrictPlanner` 文件夹整个放进：

   `文档\My Games\Sid Meier's Civilization VI\Mods\`

   - 放好后应该是 `Mods\SmartDistrictPlanner\SmartDistrictPlanner.modinfo`，不要多套一层文件夹。
   - 如果"文档"由 OneDrive 同步，实际位置在 `OneDrive\文档\My Games\…`。
   - 没有 `Mods` 文件夹就新建一个。
3. **启用。**启动游戏 → 主菜单"附加内容"，勾上 Detailed Map Tacks 和"智能区域规划器"，然后重启游戏。
4. **更新版本。**先删掉旧的 `SmartDistrictPlanner` 文件夹，再放新的。直接覆盖会留下新版已经删掉的文件。

## 2. 测试前

- **一局只开一个规划器。**关掉 Auto Map Tacks Planner、Empire Planner 等会自己打钉的模组，它们和本模组改的是同一个 DMT 函数，会互相把对方的钉当成邻居或删掉。改相邻规则、区域规则的模组也请关掉，否则结果和我们这边对不上。建议在"附加内容"里新建一个模组组，只开官方内容、DMT 和本模组。
- **新开一局，或者用存档的副本。**本模组不影响存档，打出的钉就是普通地图钉，停用模组后存档照样能读。多人游戏没测过，请先别在多人局里用。
- **打开 Lua 日志。**Steam 库 → 右键文明6 → 属性 → 启动选项，填 `-log`。日志在 `%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\Logs\Lua.log`，会跨启动追加。

## 3. 重点测什么

Mac 上已经用自动化测试验证过逻辑（游戏内 80 项、离线 58 项），也截了图。下面几项是 Mac 上测不到、或者 Windows 可能不一样的：

1. **界面布局。**请在 100% 和 150% 界面缩放、不同分辨率下各打开一次面板，看三个页签是否完整显示、有没有文字被截断或重叠。特别看两处：
   - 多城页签的权重一行（五种产出、食物、地貌、覆盖共 8 列）有没有挤出窗口；
   - 权重下面"计入占地的产出损失"和"替换本模组之前打的钉"两个勾选框是否在同一行、互不重叠。

   方便的话把游戏语言切到英文再看一遍。
2. **耗时。**Mac 上单城勾 8 个区域、标准档约 0.3 秒出结果；多城 3 座城、每城 6 个区域、标准档约 6–7 秒（分几帧算，期间游戏不卡）。请记下你那边各档位的实际等待时间，以及面板上显示的"预计"。
3. **鼠标和键盘。**Mac 上的自动化工具不能点游戏窗口，这些只能靠人：启动栏按钮、页签、勾选框、箭头、求解、继续优化、取消、方案行、打钉、撤销、Esc 关闭、Shift+L 开关面板、悬停提示。
4. **完整清单。**按 `INSTALL_AND_USE.md` 里"验收测试"一节的 20 步走一遍。每一步写"通过"或"不通过 + 现象"即可。
