# 验收与开发者测试

给维护者和测试者：发版前对照需求文档第五节的手动验收清单、Windows 冒烟测试的重点、本机排错和自动化测试的命令。玩家看的安装与使用说明在 [install-and-test.md](install-and-test.md)（压缩包里叫 `INSTALL_AND_USE.md`）。

## 验收清单（对照需求文档第五节）

以下各项都已在 macOS 上用自动化测试验证过，真实鼠标点击之外的界面操作需要人工确认，详见 [自测报告](self-test-report.md)。在 Windows 上建议按此表手动走一遍：

| # | 操作 | 预期 |
|---|------|------|
| 1 | 主菜单 → 额外内容，找到本模组 | 名称"智能区域规划器"，简介与描述为中文（英文界面下为英文） |
| 2 | 进对局，看左上启动栏；点击六边形图标 | 出现图标按钮；点击弹出面板，再点关闭；Esc 也能关闭 |
| 3 | 学院、圣地设为必建，点击求解 | 一秒内出结果；两者能相邻互惠时，结果把它们放在一起 |
| 4 | 看结果行；鼠标悬停在某一行 | 显示坐标与"科+2"这类明细；悬停显示 DMT 的逐项来源 |
| 5 | 点击打钉，关闭面板看地图；再点撤销 | 地图上出现带区域图标的钉，钉上数值与结果一致；撤销后这些钉完全消失，不会变成普通钉 |
| 6 | 选一个已建有学院的城市 | 学院格变暗、标"已建"、点了没有反应 |
| 7 | 不改任何设置，连续求解两次 | 两次结果完全相同 |
| 8 | 3–4 个区域设为必建，求解 | 游戏没有明显卡顿（停顿约 2 秒以内） |
| 9 | 单城选精细档求解，计算中关闭面板 | 计算继续；算完时启动栏按钮出现标记，重新打开面板可看到结果 |
| 10 | 选城址页签：新城数量 2，求解，点第二套方案，再点一次；点“看地图”，点“下一个城址” | 地图上预览随之切换；再点和“下一个城址”让镜头在两个城址之间来回；切换页签或关闭面板时预览消失；打城址钉后地图上出现市中心钉 |
| 11 | 多城页签：用上一步的城址钉求解，打钉 | 钉名是所属城市的编号；全帝国只有一个市政广场；撤销后钉全部消失 |
| 12 | 进入游戏的区域放置模式（如用建造者） | 规划器的预览自动清除，不干扰游戏的放置显示 |
| 13 | 按 Shift+L | 面板打开；再按一次关闭 |
| 14 | 单城：添加两个奇观，求解，打钉 | 区域和奇观一起出现在结果里，奇观钉带奇观图标 |
| 15 | 单城：好位置里选学院 | 地图上学院能放的格子按加成分档着色、标出数值；选"不显示"后消失 |
| 16 | 单城：打钉后勾选"替换本模组之前打的钉"，再求解、打钉，然后撤销 | 新方案可以用到旧钉的位置；打钉后旧钉被换掉；撤销后旧钉回来 |
| 17 | 打钉后存档、读档，点撤销 | 读档前打的钉被删除 |
| 18 | 多城：区域清单选一座城，只给它把市政广场设为必建，求解 | 市政广场只出现在这座城；悬停这座城的格子写"（自定清单）" |
| 19 | 单城：学院、剧院、商业中心、工业区设为必建，奇观选大图书馆，求解 | 大图书馆出现在结果里，并挨着学院（区域聚在一起时也不会被漏掉） |
| 20 | 多城：两三座相距 6 格左右的城，区域清单只给其中一座把工业区设为必建，覆盖权重设为 3，求解；再把覆盖设回 0 求解 | 权重 3 时工业区放在能覆盖更多城的格上，结果行写"新覆盖 N 城"，悬停列出城名；设回 0 后方案只看相邻加成和地块 |
| 21 | 单城：学院设为必建，其余占名额的区域保持候选，区域数量调到 4，求解 | 分帧算完后出现三套方案，区域组合各不相同，都含学院；点第二套，地图预览随之切换 |
| 22 | 单城：权重行最后一列"距离"调到 2，求解 | 汇总行出现"距离 −x"；区域比距离为 0 时更靠近城市（或一样近） |
| 23 | 单城：找一座缺淡水的城（无河流、湖泊、绿洲），不占名额组里水渠保持"自动"，求解 | 方案里有水渠（或本文明的替代区域），标"自动加入"；放不下时结果里说明 |
| 24 | 单城：勾"提醒钉"，规划一个旁边有两片森林的圣地并打钉 | 森林上出现"移除地貌"图标的钉，钉名以城市编号开头、写明"勿砍"和少的信仰；撤销时一起消失 |
| 25 | 多城：点一个城址钉的格子取消它，求解 | 这个城址不出现在结果里，地图上的钉还在 |
| 26 | 选城址：区域格保持默认（区域数量 3），把学院点成必建，求解 | 每个城址悬停时列出的区域不超过 3 个，都有学院；保护区、军营、航空港默认是“不建” |
| 27 | 单城、多城：连续点一个候选格，再连续点水渠（或堤坝）格；选城址同样点 | 候选 → 必建 → 不建 → 候选；自动 → 必建 → 不建 → 自动；选城址的水渠是不建 → 必建 → 不建 |
| 28 | 多城：点一个城址钉的格子，再点一次；再点“全部取消”“恢复默认” | 第一次点后格子变暗底、悬停写“不参与”，求解结果里没有它；再点恢复。全部取消后没有亮底的格子；恢复默认回到打开时的勾选 |
| 29 | 选城址打城址钉；多城页规划、打钉，再勾"替换旧钉"求解、打钉 | 市中心钉一直都在；撤销后也在 |
| 30 | 沿海城：港口、商业中心都保持候选，区域数量 3，求解 | 三套方案都不在同一座城同时挑两者。两者都设为必建时照建，结果有"同城"一行，悬停说明原因 |
| 31 | 单城：社区设为必建，求解；再把工业区也设为必建求解 | 社区放在魅力最高的可建格，结果行"住房 +x（魅力 y）"与魅力透镜一致；工业区不挨着社区，或挨着时社区住房相应少 |
| 32 | 单城：保护区默认是"不建"；点成必建，求解；再改为候选、区域数量够它被挑中时求解；再把"地块"调到 0 求解 | 必建时结果行写住房和周边地块产出，汇总行有"住房"，周边产出算在"地块"里；被挑中时周边地块一项标"候选，不计分"；地块为 0 时标"“地块”权重为 0，不计分" |
| 33 | 单城：娱乐中心、水上乐园都设为必建，求解；再都设为候选求解 | 必建时只放先列出的那个，另一个写"不能和……建在同一座城"；候选时三套方案都不在同一座城同时挑两者 |
| 34 | 单城：在沿海格很少的城同时必建港口和水上乐园 | 放下能放的那个，另一个写"没有剩余的空位"，不报错 |
| 35 | 单城：找一座有两三块农场的城，把一个区域设为必建并只留农场格可放（或看方案落在农场上时） | 结果里有一行"占掉的改良设施 住房 -x"，与城市详情里改良设施住房的变化一致（农场每块 0.5，全城加总后向下取整） |
| 36 | 有多座城的存档：在地图上点一座不是首都的城，打开面板 | 单城页签是这座城；多城页签以它为中心，默认最多 4 座连成一片的城和城址钉亮底；关掉面板再打开，手动的改动还在 |

**Windows 冒烟测试重点**：
- 模组能加载，面板布局正常（字体和窗口尺寸与 Mac 可能不同）；
- 求解耗时：Mac 实测单城 8 个区域标准档约 0.3 秒；多城 3 城 × 6 个区域标准档实际等待约 7–8 秒（分帧，游戏不卡；2026-10-21 标准档多了一个起点，游戏内实测多约 10%）。面板上的预计耗时会按本机速度自动修正；
- 打钉与撤销正常。

## 自动化测试

```bash
python3 -I tools/validate.py                                    # 静态校验
python3 -I tools/deploy.py                                      # 部署
node tools/offline_tests.mjs                                    # 离线测试（不开游戏）
python3 -I tools/game.py newgame --state SDP_Panel --capital --reveal   # 进入固定种子的测试对局并揭示首都周围
python3 -I tools/run_tests.py                                   # 游戏内测试
python3 -I tools/realclick.py suite                             # 真实鼠标点击（macOS，需辅助功能权限，会占用屏幕）
python3 -I tools/stress.py prepare NAME / load / run / check    # 发布前：后期存档压力测试
python3 -I report/build.py                                      # 生成“介绍与评测”页（dist/report/）
python3 -I tools/package.py                                     # 打出压缩包（dist/，含 tester-guide.md 和“介绍与评测”页）
```

Windows 上把 `python3 -I` 换成 `py -3 -I`；`realclick.py` 只能在 macOS 上用。环境搭建见 [dev-macos.md](dev-macos.md)、[dev-windows.md](dev-windows.md)，工具说明见 [tools/README.md](../tools/README.md)。

## 排错（开发者）

- **macOS**：游戏不写 `Lua.log`，用 `tools/civ6tuner.py serve` 收集 Lua 输出，见 [tools/README.md](../tools/README.md)。
- **Windows**：在 Steam 启动项加 `-log` 后看 `%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\Logs\Lua.log`，先搜 `Runtime Error`，再搜 `SDP_`（需求文档第四节）。
- 部署：`python3 -I tools/deploy.py` 校验后把 `SmartDistrictPlanner/` 同步到游戏的 Mods 目录。
