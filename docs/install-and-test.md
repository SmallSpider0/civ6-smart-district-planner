# 安装与测试

交付物 2。

## ⚠️ 请勿与其他区域规划模组同时启用

**不要与 Auto Map Tacks Planner（AMT）或其他自动规划地图钉的模组同开。**原因有两点：
- 它们同样改写 DMT 的地图钉读写函数（`GetMapPinSubject`），也会自己新建、删除地图钉；
- 两个规划器同开时，会把对方的钉当成锁定邻居，或把对方的钉删掉，结果互相污染。

一局游戏只开一个规划器。各规划器规划什么，见 README 的[同类模组](../README.md#同类模组)。

| 项目 | 要求 |
|------|------|
| 游戏 | 《文明6》原版、迭起兴衰（R&F）或风云变幻（GS）规则集均可，运行时自动识别 |

## 安装

1. 在 Steam 创意工坊订阅[智能区域规划器](https://steamcommunity.com/sharedfiles/filedetails/?id=3824473635)和 Detailed Map Tacks。
2. 不用创意工坊时：把整个 `SmartDistrictPlanner/` 文件夹复制到本地 Mods 目录（DMT 仍要在创意工坊订阅）：
   - Windows：`文档\My Games\Sid Meier's Civilization VI\Mods\`
   - macOS：`~/Library/Application Support/Sid Meier's Civilization VI/Sid Meier's Civilization VI/Mods/`

   复制后应为 `Mods\SmartDistrictPlanner\SmartDistrictPlanner.modinfo`。开发者可以直接运行 `python3 -I tools/deploy.py`。只留一份：Mods 里和创意工坊各有一份时，游戏只加载其中一份，不一定是新的，也不一定是在“额外内容”里启用的那份（2026-10-22 在 macOS 上实测）。改用创意工坊版时先删掉 Mods 里的文件夹。
3. 启动游戏，进入主菜单的"额外内容"，确认 **Detailed Map Tacks** 和 **智能区域规划器** 都已启用。
   - 新安装的模组在自建的模组组里默认**未启用**，需要手动勾选；在默认组里则会自动启用。
   - 修改模组启用状态或更新 modinfo 后需要重启游戏。

## 使用

面板顶部有三个页签：**单城**、**选城址**、**多城**。下面先说单城，再说另外两个。

### 单城

1. 进入对局后，屏幕左上角启动栏末尾会多出一个六边形图钉图标，悬停提示"智能区域规划器"和版本号。点击打开面板，再点一次或按 Esc 关闭。也可以按 **Shift+L** 打开或关闭（可在游戏的"选项 → 按键"里改，类别"智能区域规划器"）。
   - 窗口高度跟着屏幕：低屏缩短、高屏加高，差出的高度都由结果列表承担。
   - 标题栏左侧的 **看地图** 先收起窗口，地图上的方案预览留着；点屏幕左上的 **返回规划器** 或按 Esc 回来。
   - 三个页签的开关、权重、档位和设置区收起与否各自记在存档里，读档后还是上次的样子；不发给其他玩家。区域的必建、候选、不建不记。
2. **城市**：默认是地图上当前选中的本方城市，没有选中时为首都；可在下拉框中切换。之后在地图上选中另一座本方城市再打开面板，面板打开在单城页签，城市切到那座城；没选城市、或选的还是上次那座时，打开的是上次关面板时的页签（后台正在计算时都不切）。
3. **区域**：分两组排成网格，列表里的区域已按本文明替换为特色区域。点一下格子切换状态：
   - **占人口名额的区域**：候选 → 必建 → 不建。必建的一定放；候选的在"区域数量"多于必建个数时参与挑选；不建的不考虑。全帝国限一个的区域（如市政广场）只有必建、不建。
   - **不占名额的区域**（水渠、堤坝、运河、社区、宇航中心等）：自动 → 必建 → 不建。"自动"只出现在水渠类和堤坝上：城市缺淡水时自动加水渠；三环内本城能用的泛滥平原不少于 3 格时自动加堤坝（只在风云变幻）。位置照常求解，结果里标"自动加入"。
   - 本城已建的区域、全帝国已达上限的区域变暗，不能点，格子右侧写原因。
   - **港口、商业中心分城**（"占人口名额的区域"标题行中间的开关，默认勾选）：灯塔的贸易路线容量要求本城没有市场（原版：港口的贸易路线容量要求本城没有商业中心），两者建在同一座城只多 1 条贸易路线，分在两座城多 2 条。勾选时从候选里挑区域不会让一座城同时有这两种区域：城里已有其中一个（已建、已打钉或设为必建）就不挑另一个；只有不这样就凑不够区域数量时才两个都挑，结果里会提示。设为必建的照建。规则从游戏数据读，特色区域（英国皇家海军船坞、腓尼基U型港、马里曼丁哥市场）同样处理；原版的皇家海军船坞自带一条不受限的贸易路线，不和商业中心分城。
4. **区域数量**（城市右侧）：要规划几个占人口名额的区域，必建的也算在内。默认 3（必建的多于 3 个时等于必建个数），打开面板直接求解就会从候选里挑。调到等于必建个数时只放必建的；多出的个数从候选里挑相邻加成最高的，并给出区域组合不同的三套方案。下方显示特色区域名额：已建数、本次数量、当前人口上限，超出时只提示，不阻止。
   - 挑选按加权相邻加成（打开时加上地块、距离成本）比较，社区、保护区再加上住房和保护区周边地块的产出（见权重的"住房"）。军营、航空港这类没有相邻加成的区域放在候选里不会被挑中，需要时设为必建。
5. **设置摘要**：区域网格下面的一行写着当前的设置（如"设置：均衡 · 奇观 1"，改过权重时写"均衡（已改）"），下面的奇观、好位置、权重和开关可以收起。求解后自动收起，点这一行展开或收起。
   **奇观**：从"添加奇观"下拉框选，选中的显示成标签，点标签上的"×"去掉；可以选多个。已建成或已有钉的奇观不列出。选了奇观时，这座城按"多城"的方法求解（奇观放在区域之后，需要相邻某区域的奇观会挨着它）。
   - 需要相邻某区域的奇观（如罗马斗兽场要挨着娱乐中心）：这座城没有这个区域（已建、为这座城打了钉、设为必建或自动加入）时，网格里它的格子显示"随奇观"，求解时当作必建一起规划，结果行标"供罗马斗兽场相邻"；它算在区域数量里。你把这个区域点成"不建"时不补，奇观放不下并写明缺哪个区域；去掉奇观，格子恢复原状。两个奇观要同一种区域时只补一个。全帝国限一个的区域（市政广场）已在别的城时补不了，结果写明它在哪座城。
   **好位置**：下拉框里选一个区域，地图上把它能放的每一格按"单独放在这里的加成"从高到低分四档着色并标出数值，方便手动摆放；选"不显示"、求解、换城市或改设置时取消。
6. **权重**（标题"权重（0–3）"；图标为游戏的字体图标，悬停看名称）：每项 0–3，每点一下改 0.5。标题行右侧的**预设**：均衡（全 1）、科技（科学 1.5）、文化（文化 3）、宗教（信仰 3）、金币信仰减半（金币、信仰 0.5），选一个就把权重和开关设好；改过以后写“（已改）”，点**恢复**回到预设的值。科学、文化、信仰、金币、生产力，默认 1；**地块**（默认 1）：区域占掉城市本来要耕作的好地块时，这部分损失乘以它计入，0 表示不计。地块按修上最好的改良后的产出算（如丘陵按矿山），砍伐、收获按先收再建计，不算损失，结果行会提示"先砍伐或收获"；地块的各项产出按固定倍数折算，不随产出权重变：食物、生产力 1，科技、文化 5/6，信仰 1/2，金币 1/4（1 生产力 = 4 金币 = 2 信仰），砍伐、收获的一次性产出也一样。**距离**（默认 0）：每个区域、奇观按到最近的本方市中心的格数减 1 乘以它扣分，想让区域靠近城市时调高。游戏里区域造价与距离无关，这里只是偏好。最后一列 **住房**（0–3，默认 1）：社区、保护区按所在格的魅力提供住房（社区：惊艳 6、迷人 5、普通 4、无吸引力 3、令人厌恶 2；保护区 1 加同样的增减），每座城的住房到建齐计划区域所需人口为止每点算 1，之后每多一点减半，再乘这个权重；保护区的古树林、避难所给周围未开发地块按魅力加的产出按地块的固定倍数计（地块权重大于 0 时只算城市会耕作的地块，再乘地块权重）。魅力随方案变化：圣地、剧院、娱乐中心等让相邻格 +1，工业区、军营、航空港等 -1，区域建在树林上会砍掉树林、让周围格 -1。已有或已打钉的社区也计入，方案让它的魅力降档时要付出代价。**覆盖**（0–3，默认 0，即不计）：与多城页签的同名列相同（见下文“多城”第 4 步）；单城页签把本方其他城市和全部城址钉都算作要覆盖的城。
7. **开关**（一行，悬停看完整说明）：
   - **允许砍伐**：默认勾选；取消后方案不会放在树林、雨林、沼泽上；
   - **替换旧钉（n）**：默认不勾选，此时所有已有的钉（包括本模组打的）都是锁定的。勾选后，本模组之前为这座城打、且你没改过名称和图标的钉在规划时当作不存在，打新钉时先删掉它们；撤销会把它们放回。你自己打的钉永远不动；
   - **提醒钉**：默认勾选。方案里的区域靠旁边的树林、雨林拿相邻加成时，打钉会在这些格子上一起打一个"移除地貌"图标的钉，钉名写明砍掉会少多少（如"1 勿砍：圣地 信-1"）。
8. **档位**：快速、标准（默认）、精细，旁边显示预计耗时；悬停每一档可看到离线基准上的实测耗时和质量。快速、标准档不挑选时立即出结果；挑选候选、选了奇观或精细档时分几帧计算，期间游戏照常操作，"继续优化"变成"取消"；关闭面板也会继续算，算完时启动栏按钮上出现标记并播放提示音。
9. 点击 **求解**（没有必建区域、区域数量为 0、也没选奇观时按钮是灰的）：
   - 出结果和换方案时，镜头把城市移到面板右边。
   - 有多套方案时排成一行按钮（"方案 1：+18"），悬停看挑出的区域，点一个即显示该方案，并在地图上预览区域图标和数值。
   - 结果列出每个区域的坐标和产出（如"科+2"），悬停可看到 DMT 给出的逐项来源，点一行镜头移到那一格；自动加入、从候选挑出的另有标注。社区、保护区写"住房 +6（魅力 4）"，保护区另写"周边地块 食+2 信+2 ……"。
   - 港口与商业中心在同一座城时（都设为必建，或不这样凑不够数量），多一行"港口与商业中心同城：灯塔不增加贸易路线"。
   - "勿砍树林 (x, y)"一行说明方案依赖的地貌和砍掉会少的产出。
   - 相邻已有区域或已有地图钉的加成如果因此变化，也会列出（"已有 学院 (x, y)，加权分 0 → 1"）。放不下的区域会列出原因。
   - 汇总行显示加权提升和各部分（相邻、地块、距离，有社区、保护区时还有"住房与魅力"），悬停可看到求解统计；下一行是质量说明（已证明最优，或离估计上界还有多远）。
10. **继续优化**：在当前结果上再多搜索一轮，结果只会变好或不变。
11. 点击 **打钉**：给当前显示的方案每个位置打一个带区域图标的地图钉（勾选提醒钉时连同提醒钉）。DMT 会在钉上显示产出，数值与结果列表一致。
12. 点击 **撤销**：删除最近一次打出的钉，可多次撤销；替换过旧钉的那次撤销会把旧钉放回。撤销只删除本模组打的、仍在原位且没被改过的钉，玩家自己的钉不受影响。撤销记录随存档保存，读档后仍可撤销。

### 选城址

1. 设定**新城数量**（1–6）和**最远距离**（4–15 格，默认 5：新城离本方城市、城址钉或另一座新城最多几格，按两个城市中心之间的格数算；新城通常正好放在这个距离上）。这两项和权重一样记在存档里。
2. 选**权重预设**（均衡、成长优先、区域优先）或逐项调整（每点一下改 0.5）：五种产出、距离成本、食物、住房、宜居度、战略资源、地貌、魅力。预设和权重同单城一样收在一行摘要下面，求解后自动收起。城址的地块产出按单城“地块”列说明里的固定倍数折算，再乘这里同一产出的权重（“成长优先”的食物 2 就是食物格加倍）。住房指城址的水源住房（加粮仓；计划里有港口时加灯塔、海港），到建齐计划区域所需人口为止每点算 1，之后每多一点减半。
3. 勾选**用于给城址估算区域分的区域**，右侧的"每个城址按 N 个"（默认 3）：勾选的占名额区域多于 N 个时，每个城址各自挑区域分最高的 N 个；不多于时全部计入。
4. 选档位后点 **求解**。结果给出最多三套方案，点一套即在地图上预览（各城址的三环着色，图标标出城址号和分数，不打钉），镜头移到它的第一个城址；再点一次这套方案，镜头移到下一个城址，最后一个之后回到第一个。下方列出每座城址的分项，点一行镜头移到这个城址，悬停列出它挑中的区域。“看地图”时，“返回规划器”旁边有 **下一个城址**。
5. 点 **打城址钉**：在每个城址打一个市中心图标的钉，名称是城址的编号（接在现有城市之后，例如已有 3 座城时为"4""5"）。这些钉随后自动进入"多城"页签。
- 只考虑已揭示的地块；三环多半没揭示的格子不作候选。

### 多城

1. **参与城市**：本方全部城市和城址钉（还没建城的市中心钉）排成格子，每行 3 格，最多显示 5 行，更多时滚动。城址钉在前，城市按编号排；点一格切换它是否参与，参与的用亮底。
   - 默认以打开面板时地图上选中的本方城市为中心，没有选中时是首都：勾选它，再按离它由近到远，加入离已勾选的某座不超过 7 格的城市和城址钉，最多 4 座。在地图上换一座城再打开面板，中心随之改变，手动的勾选回到默认（后台正在计算时不变）。
   - 手动最多 8 座；选满后其余格子变暗，先取消一座才能选。标题右侧有 **全部取消** 和 **恢复默认**。
   - 不参与的城市只作固定邻居（已建区域和钉计入总分但不动）；不参与的城址钉不规划区域、不算新城，钉还在。
   - 一起规划的城越多等得越久；悬停标题看实测的耗时和联合规划多得的相邻加成。
2. **区域**：
   - **区域清单**下拉框默认是"所有城市（共用清单）"，已建和已有钉的会自动跳过（只认这座城自己的钉：本模组为它打的钉，以及在它的格上、或在离它最近的无主格上的钉），跳过已有钉的区域在结果里列出。选某座城后，网格只改这座城自己的清单（第一次改动时从共用清单复制一份），悬停城市的格子会看到"（自定清单）"。
   - 网格与单城相同（必建、候选、不建、自动）；标题右侧的**每城数量**是这份清单每座城要规划几个占人口名额的区域（默认 3），多于必建个数时由求解器为每座城从候选里挑；套用模板只换区域，不改数量。
   - **套用模板**：按产出给出"科技城""文化城""信仰城""金币城""生产力城"等模板，内容是本文明能从相邻加成得到该产出的区域（从游戏规则读取，特色区域自动替换），设为必建；也可"清空清单"，或让某座城"改回共用清单"。
   - **市政广场等全帝国限 1 个的区域**：在共用清单里设为必建时，放在城市列表里最靠前的那座城，其他城标“已达帝国上限”，改从候选里补足每城数量；想放在别的城，就只在那座城自己的清单里设为必建（悬停格子可看到）；都不建就不放。你任何一座城已经建了（建完或在建），格子显示“已建”、变灰、点不动，悬停写明建在哪座城，不会再规划第二座。
3. **奇观**：与单城相同的标签和"添加奇观"下拉框。需要相邻某区域的奇观，参与的城里都没有这个区域（已建、已打钉或清单里设为必建）时，求解时补给城市列表里排在最前、能放下它的那座城；奇观标签下有一行说明，求解后写明补给了哪座城。想指定哪座城，就给那座城开自己的清单并把这个区域设为必建。共用清单不会因此改动，你在清单里把它点成"不建"时不补。
4. **权重**与单城相同（含"地块"一列），最后一列 **覆盖**（0–3，默认 0，即不计）：大于 0 时，工业区、娱乐中心、水上乐园和斗兽场这类有覆盖范围的奇观，会尽量放在能覆盖更多本方城市（包括城址）的格上。
   - 每新覆盖一座城记"权重"分，与相邻加成同一单位。覆盖半径从游戏规则读（风云变幻：工业区、娱乐中心 6 格，水上乐园 9 格）；已建、已打钉的同类区域已覆盖到的城不再计。
   - 从候选里挑区域时也计覆盖：权重高时，能覆盖邻城的工业区、娱乐中心可能比别的候选先被挑中。
   - 结果摘要里单列覆盖分，悬停按类别列出新覆盖的城；有覆盖范围的区域那一行写"新覆盖 N 城"（只数以前没被同类区域覆盖的城），悬停列出城名。
5. **开关**：替换旧钉（作用于所有参与的城市；选城址页打的市中心钉不会被替换）、提醒钉；"占人口名额的区域"标题行中间是港口、商业中心分城（同单城，按每座城分别判断）。
6. 选档位后点 **求解**（分帧计算）。设置区随之收起（同单城）。结果最多三套方案，排成一行按钮，点一套即在地图上预览，区域钉下的文字前面是所属城市的编号；下方按城列出每个区域的位置和加成。
7. 点 **打钉**：钉名是所属城市的编号（图标已经表明是什么区域），面板里城市也带同样的编号，如"1 罗马""城址 4"；**撤销**同单城。


**规则说明**
- 已有地图钉一律视为锁定：它所在的格子不会被占用，它的产出计入方案总分。
- 想重新规划时，撤销之前打出的钉，或勾选"替换本模组之前打的钉"。
- 城市已拥有的格子上，除 DMT 的规则外还以游戏自己的可建格为准（游戏不允许的格子不会出现在方案里，例如不连通水域的运河）；城市还没拥有的格子、尚未解锁的区域，游戏不给结果，仍按 DMT 判断。
- 城址钉（还没建城的市中心钉）一环内没有主人的格子留给这座新城：建城时它会拿走这些格子，所以别的城不会在上面规划区域。
- **从本方其他城换格**（单城、多城页的开关，默认关闭）：打开后，属于本方另一座城、能在“市民管理”里用“切换”改归本城的格（挨着本城领土、格上没有区域或奇观、不挨着那座城的市中心）也可以放区域，结果写“需从某城换格”；那格原来的耕作产出算作原来那座城的损失。收益和代价（实测的提升百分比、要手动切换的格数、耗时）写在开关的悬停提示里。
- 同一局面、同样的输入，求解结果每次都相同。

## 排错

- **Windows**：Lua 日志在 `%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\Logs\Lua.log`，需要在 Steam 启动项加 `-log`（需求文档第四节）。日志跨启动追加，先搜 `Runtime Error`，再搜 `SDP_`。
- **macOS**：游戏不写 `Lua.log`，用 `tools/civ6tuner.py serve` 收集 Lua 输出，见 [tools/README.md](../tools/README.md)。
- **按钮或面板不出现**：确认 DMT 已启用（本模组依赖它）；改过 modinfo 或文本后要重启游戏。
- **面板没有弹出**：游戏的其他弹窗（如"历史时刻"）优先级更高，规划面板会等它们关闭后再显示。
- **某个区域"范围内没有合法位置"**：城市三环内没有符合该区域放置规则的格子。例如港口需要海岸；未揭示的格子和别人的领土也不在考虑范围内。

## 已知限制

- 多城页签没有"允许砍伐"开关（始终允许）。
- 候选格只取城市的领土能连到的格（游戏只允许扩张或购买挨着自己领土的格）；多城方案里别的城的区域也算挡住。中间的无主格以后归谁，取决于文化扩张和购买的先后，所以结果里标“需先扩张或购买”的格要玩家自己买下或等扩张。奇观不参与这条判断。
- 多城与选城址的方案要全部算完才列出。
- 选城址的分数是估计值：地块产出、资源和区域潜力按当前已揭示的信息估算，区域在"多城"一步精确规划。
- 每种区域只规划一个；社区等可重复建造的区域如需多个，需分次求解。
- 挑选候选时只比相邻加成（及打开的地块、覆盖、距离成本），区域里建筑本身的产出不计。
- 提醒钉只提醒规划的区域旁边的树林、雨林；已有区域旁边的地貌不提醒。
- 未揭示的格子不参与规划：DMT 在这类格子上读不到地形。
- 多人游戏未测试；打出的钉使用游戏默认的可见性。
- 魅力以游戏现在的值为底（文明、总督、政策、奇观的修正已含在内），加上方案里区域、奇观和清掉的地貌、改良设施带来的变化；方案之外以后才建的改良设施不在模型里。保护区周边产出假设那些地块一直不开发；打钉的保护区只计住房。
