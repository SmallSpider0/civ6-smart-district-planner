# 安装与测试

交付物 2。

## ⚠️ 请勿与其他区域规划模组同时启用

**不要与 Auto Map Tacks Planner（AMT）或其他自动规划地图钉的模组同开。**原因有两点：
- 它们同样改写 DMT 的地图钉读写函数（`GetMapPinSubject`），也会自己新建、删除地图钉；
- 两个规划器同开时，会把对方的钉当成锁定邻居，或把对方的钉删掉，结果互相污染。

一局游戏只开一个规划器。

## 前置条件

| 项目 | 要求 |
|------|------|
| 游戏 | 《文明6》原版、迭起兴衰（R&F）或风云变幻（GS）规则集均可，运行时自动识别 |
| 依赖模组 | **Detailed Map Tacks**（DMT，Steam 创意工坊 2428969051），需订阅并启用 |
| 已测平台 | macOS 版 1.0.12.54（Aspyr），三种规则集各跑过一遍全部自动化测试；Windows 版未实测，见下文"Windows 冒烟测试" |

## 安装

1. 在 Steam 创意工坊订阅 Detailed Map Tacks。
2. 把整个 `SmartDistrictPlanner/` 文件夹复制到本地 Mods 目录：
   - Windows：`文档\My Games\Sid Meier's Civilization VI\Mods\`
   - macOS：`~/Library/Application Support/Sid Meier's Civilization VI/Sid Meier's Civilization VI/Mods/`

   复制后应为 `Mods\SmartDistrictPlanner\SmartDistrictPlanner.modinfo`。开发者可以直接运行 `python3 -I tools/deploy.py`。
3. 启动游戏，进入主菜单的"附加内容"，确认 **Detailed Map Tacks** 和 **智能区域规划器** 都已启用。
   - 新安装的模组在自建的模组组里默认**未启用**，需要手动勾选；在默认组里则会自动启用。
   - 修改模组启用状态或更新 modinfo 后需要重启游戏。

## 使用

面板顶部有三个页签：**单城**、**选城址**、**多城**。下面先说单城，再说另外两个。

### 单城

1. 进入对局后，屏幕左上角启动栏末尾会多出一个六边形图钉图标，悬停提示"智能区域规划器"。点击打开面板，再点一次或按 Esc 关闭。也可以按 **Shift+L** 打开或关闭（可在游戏的"选项 → 按键"里改，类别"智能区域规划器"）。
2. **城市**：默认是地图上当前选中的本方城市，没有选中时为首都；可在下拉框中切换。
3. **区域**：分两组排成网格，列表里的区域已按本文明替换为特色区域。点一下格子切换状态：
   - **占人口名额的区域**：候选 → 必建 → 不建。必建的一定放；候选的在"区域数量"多于必建个数时参与挑选；不建的不考虑。全帝国限一个的区域（如政府广场）只有必建、不建。
   - **不占名额的区域**（水渠、水坝、运河、社区、航天中心等）：自动 → 必建 → 不建。"自动"只出现在水渠类和水坝上：城市缺淡水时自动加水渠；三环内本城能用的泛滥平原不少于 3 格时自动加水坝（只在风云变幻）。位置照常求解，结果里标"自动加入"。
   - 本城已建的区域、全帝国已达上限的区域变暗，不能点，格子右侧写原因。
4. **区域数量**（城市右侧）：要规划几个占人口名额的区域，必建的也算在内。默认等于必建个数，这时只放必建的。调大后，多出的个数从候选里挑相邻加成最高的，并给出区域组合不同的三套方案。下方显示特色区域名额：已建数、本次数量、当前人口上限，超出时只提示，不阻止。
   - 挑选按加权相邻加成（打开时加上地块、距离成本）比较。军营、航空港这类没有相邻加成的区域放在候选里不会被挑中，需要时设为必建。
5. **奇观**：从"添加奇观"下拉框选，选中的显示成标签，点标签上的"×"去掉；可以选多个。已建成或已有钉的奇观不列出。选了奇观时，这座城按"多城"的方法求解（奇观放在区域之后，需要相邻某区域的奇观会挨着它）。
   **好位置**：下拉框里选一个区域，地图上把它能放的每一格按"单独放在这里的加成"从高到低分四档着色并标出数值，方便手动摆放；选"不显示"、求解、换城市或改设置时取消。
6. **权重**（图标为游戏的字体图标，悬停看名称）：科学、文化、信仰、金币、生产力，每项 0–3，默认 1；食物、地貌只用于占地损失；最后一列 **距离**（0–3，步长 0.5，默认 0）：每个区域、奇观按到最近的本方市中心的格数减 1 乘以它扣分，想让区域靠近城市时调高。游戏里区域造价与距离无关，这里只是偏好。
7. **开关**（一行，悬停看完整说明）：
   - **计入占地**：默认勾选，区域占掉城市本来要耕作的好地块时扣除这部分损失；
   - **允许砍伐**：默认勾选；取消后方案不会放在树林、雨林、沼泽上；
   - **替换旧钉（n）**：默认不勾选，此时所有已有的钉（包括本模组打的）都是锁定的。勾选后，本模组之前为这座城打、且你没改过名称和图标的钉在规划时当作不存在，打新钉时先删掉它们；撤销会把它们放回。你自己打的钉永远不动；
   - **提醒钉**：默认勾选。方案里的区域靠旁边的树林、雨林拿相邻加成时，打钉会在这些格子上一起打一个"移除地貌"图标的钉，钉名写明砍掉会少多少（如"1 勿砍：圣地 信-1"）。
8. **档位**：快速、标准（默认）、精细，旁边显示预计耗时。快速、标准档不挑选时立即出结果；挑选候选、选了奇观或精细档时分几帧计算，期间游戏照常操作，"继续优化"变成"取消"；关闭面板也会继续算，算完时启动栏按钮上出现标记并播放提示音。
9. 点击 **求解**：
   - 有多套方案时列出方案行（"方案 1：+18  挑出：剧院广场、商业中心"），点一行即显示该方案，并在地图上预览区域图标和数值。
   - 结果列出每个区域的坐标和产出（如"科+2"），悬停可看到 DMT 给出的逐项来源；自动加入、从候选挑出的另有标注。
   - "勿砍树林 (x, y)"一行说明方案依赖的地貌和砍掉会少的产出。
   - 相邻已有区域或已有地图钉的加成如果因此变化，也会列出（"已有 学院 (x, y)，加权分 0 → 1"）。放不下的区域会列出原因。
   - 汇总行显示加权提升和各部分（相邻、地块、距离），悬停可看到求解统计；下一行是质量说明（已证明最优，或离估计上界还有多远）。
10. **继续优化**：在当前结果上再多搜索一轮，结果只会变好或不变。
11. 点击 **打钉**：给当前显示的方案每个位置打一个带区域图标的地图钉（勾选提醒钉时连同提醒钉）。DMT 会在钉上显示产出，数值与结果列表一致。
12. 点击 **撤销**：删除最近一次打出的钉，可多次撤销；替换过旧钉的那次撤销会把旧钉放回。撤销只删除本模组打的、仍在原位且没被改过的钉，玩家自己的钉不受影响。撤销记录随存档保存，读档后仍可撤销。

### 选城址

1. 设定**新城数量**（1–6）和**最远距离**（4–15 格：新城离本方城市或另一座新城最多几格）。
2. 选**权重预设**（均衡、成长优先、区域优先）或逐项调整：五种产出、距离成本、食物、宜居度、战略资源、地貌、魅力。
3. 勾选**用于给城址估算区域分的区域**，右侧的"每个城址按 N 个"（默认 3）：勾选的占名额区域多于 N 个时，每个城址各自挑区域分最高的 N 个；不多于时全部计入。
4. 选档位后点 **求解**。结果给出最多三套方案，点一套即在地图上预览（各城址的三环着色，图标标出城址号和分数，不打钉）；下方列出每座城址的分项，悬停列出它挑中的区域。
5. 点 **打城址钉**：在每个城址打一个市中心图标的钉，名称是城址的编号（接在现有城市之后，例如已有 3 座城时为"4""5"）。这些钉随后自动进入"多城"页签。
- 只考虑已揭示的地块；三环多半没揭示的格子不作候选。

### 多城

1. **参与城市**：全部市中心钉（新城），加上离任一新城 7 格内的本方城市（最多 8 座）。每一项都可以取消勾选：取消的城址钉不参与规划，但钉还在，仍作为固定邻居；附近的城市是否默认参加只按仍参与的城址计算。
2. **区域**：
   - **区域清单**下拉框默认是"所有城市（共用清单）"，已建和已有钉的会自动跳过。选某座城后，网格只改这座城自己的清单（第一次改动时从共用清单复制一份），城市列表里标"（自定清单）"。
   - 网格与单城相同（必建、候选、不建、自动）；标题右侧的**每城数量**是这份清单每座城要规划几个占人口名额的区域，多于必建个数时由求解器为每座城从候选里挑。
   - **套用模板**：按产出给出"科技城""文化城""信仰城""金币城""生产力城"等模板，内容是本文明能从相邻加成得到该产出的区域（从游戏规则读取，特色区域自动替换），设为必建；也可"清空清单"，或让某座城"改回共用清单"。
   - **政府广场等全帝国限 1 个的区域**：在共用清单里设为必建时，由求解器在各城中选最好的位置；只在某座城自己的清单里必建时，就只放在这座城（悬停格子可看到）；都不建就不放。
3. **奇观**：与单城相同的标签和"添加奇观"下拉框。
4. **权重**与单城相同，另有最后一列 **覆盖**（0–3，默认 0，即不计）：大于 0 时，工业区、娱乐中心、水上乐园和斗兽场这类有覆盖范围的奇观，会尽量放在能覆盖更多本方城市（包括城址）的格上。
   - 每新覆盖一座城记"权重"分，与相邻加成同一单位。覆盖半径从游戏规则读（风云变幻：工业区、娱乐中心 6 格，水上乐园 9 格）；已建、已打钉的同类区域已覆盖到的城不再计。
   - 覆盖只决定区域放在哪，不会替哪座城加区域。
   - 结果摘要里单列覆盖分；有覆盖范围的区域那一行写"覆盖 N 城"，悬停列出城名。
5. **开关**：计入占地、替换旧钉（作用于所有参与的城市）、提醒钉。
6. 选档位后点 **求解**（分帧计算）。结果最多三套方案，点一套即在地图上预览；下方按城列出每个区域的位置和加成。
7. 点 **打钉**：钉名是所属城市的编号（图标已经表明是什么区域），面板里城市也带同样的编号，如"1 罗马""城址 4"；**撤销**同单城。


**规则说明**
- 已有地图钉一律视为锁定：它所在的格子不会被占用，它的产出计入方案总分。
- 想重新规划时，撤销之前打出的钉，或勾选"替换本模组之前打的钉"。
- 城市已拥有的格子上，除 DMT 的规则外还以游戏自己的可建格为准（游戏不允许的格子不会出现在方案里，例如不连通水域的运河）；城市还没拥有的格子、尚未解锁的区域，游戏不给结果，仍按 DMT 判断。
- 同一局面、同样的输入，求解结果每次都相同。

**Windows 冒烟测试重点**：
- 模组能加载，面板布局正常（字体和窗口尺寸与 Mac 可能不同）；
- 求解耗时：Mac 实测单城 8 个区域标准档约 0.3 秒；多城 3 城 × 6 个区域标准档实际等待约 7–8 秒（分帧，游戏不卡；2026-10-21 标准档多了一个起点，游戏内实测多约 10%）。面板上的预计耗时会按本机速度自动修正；
- 打钉与撤销正常。

## 排错

- **Windows**：Lua 日志在 `%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\Logs\Lua.log`，需要在 Steam 启动项加 `-log`（需求文档第四节）。日志跨启动追加，先搜 `Runtime Error`，再搜 `SDP_`。
- **macOS**：游戏不写 `Lua.log`，用 `tools/civ6tuner.py serve` 收集 Lua 输出，见 [tools/README.md](../tools/README.md)。
- **按钮或面板不出现**：确认 DMT 已启用（本模组依赖它）；改过 modinfo 或文本后要重启游戏。
- **面板没有弹出**：游戏的其他弹窗（如"历史时刻"）优先级更高，规划面板会等它们关闭后再显示。
- **某个区域"范围内没有合法位置"**：城市三环内没有符合该区域放置规则的格子。例如港口需要海岸；未揭示的格子和别人的领土也不在考虑范围内。

## 已知限制

- 多城页签没有"允许砍伐"开关（始终允许）。
- 覆盖范围只在多城页签计入；单城页签不考虑区域能覆盖几座邻城。
- 多城与选城址的方案要全部算完才列出。
- "需要相邻某区域"的奇观（如需相邻港口的奇观）只按 DMT 判断相邻，不要求该区域属于同一座城。
- 选城址的分数是估计值：地块产出、资源和区域潜力按当前已揭示的信息估算，区域在"多城"一步精确规划。
- 每种区域只规划一个；社区等可重复建造的区域如需多个，需分次求解。
- 挑选候选时只比相邻加成（及打开的地块、覆盖、距离成本），区域里建筑本身的产出不计。
- 提醒钉只提醒规划的区域旁边的树林、雨林；已有区域旁边的地貌不提醒。
- 未揭示的格子不参与规划：DMT 在这类格子上读不到地形。
- 多人游戏未测试；打出的钉使用游戏默认的可见性。

## 开发者：自动化测试

```bash
python3 -I tools/validate.py                                    # 静态校验
python3 -I tools/deploy.py                                      # 部署
node tools/offline_tests.mjs                                    # 离线测试（不开游戏）
python3 -I tools/game.py newgame --state SDP_Panel --capital --reveal   # 进入固定种子的测试对局并揭示首都周围
python3 -I tools/run_tests.py                                   # 游戏内测试
python3 -I report/build.py                                      # 生成交付报告（dist/report/）
python3 -I tools/package.py                                     # 打出给合作者的测试包（dist/，含 tester-guide.md 和交付报告）
```

工具说明见 [tools/README.md](../tools/README.md)。
