# #199 勾了奇观后“求解”按钮落到屏幕下面（2026-11-02）

创意工坊玩家反馈：打开面板、勾上奇观后面板变长，底部的“求解”按钮被屏幕下边缘挡住，面板又拖不动。

## 原因

#71 让窗口高度跟屏幕走（`SDP_UI.WindowHeight`），页面里只有结果列表的高度会变（`SDP_UI.FitResults`：取页面剩下的高度，最少一行 40）。两处没管到：

1. **勾、取消奇观后不重排。** `FitPage` 只在出结果、折叠、换屏高时跑；`SetWonder` 里的 `ClearResult` 只在已有结果时才走到 `ShowResult`。打开面板时结果列表已经占满剩下的高度，之后每多一行奇观标签（每个标签高 24，加间距 28），“求解”、结果和打钉按钮整体往下移 28，移出窗口和屏幕。多城页的 `ShowWonders` 一样。
2. **设置区本身放不下时没地方缩。** 结果列表缩到一行后，设置区（奇观标签、权重、开关）还是全部画出来；屏幕矮或奇观多时页面仍然超出（#71 的记录里已写：屏幕低于约 760 时展开的单城页可能超出）。

## 改动

- 三个页签的设置区 Stack 套进 `ScrollPanel`（`SettingsScroll`、`SitesSettingsScroll`、`MultiSettingsScroll`；`AutoScrollBar`，滚动条 `AnchorSide="O,I"` 放在框外右侧，不盖住右对齐的下拉框，先例见游戏本体带 `Slider_Blue` 的滚动条）。下拉框放在 ScrollPanel 里，游戏本体的 `Options.xml` 也这样用。
- `SDP_UI.FitResults(body, page, scroll, settings, settingsStack)`：先让滚动框等于设置区画出的高度，结果列表缩到一行；还超出时，滚动框缩掉超出的部分，最少 `SETTINGS_MIN`（56，约两行），然后结果列表取剩下的。
- 折叠隐藏的是滚动框（原来是里面的 Stack）。
- 单城页 `PopulateWonders`、多城页 `ShowWonders` 末尾重新 `FitPage`。

## 测试

- 离线 `spec_panel.lua` “issue 199”：用一个假布局（固定部分 340，设置区 150 加每两个奇观一行 28，加结果列表），768 的屏（页面 548），从下拉框逐个勾上全部奇观：页面放得下、设置区滚动、结果列表一行；折叠后结果列表占满；取消后设置区恢复全高。多城页同样。旧代码上失败：勾完 5 个奇观后页面 614 > 548。
- 游戏内 `tests/test_ui.lua` “issue 199”：真实布局，勾上全部可选奇观，在本机屏幕和最矮的页面（窗口最小 640）各查一次：页面放得下，“求解”按钮的下沿在页面和屏幕之内。
