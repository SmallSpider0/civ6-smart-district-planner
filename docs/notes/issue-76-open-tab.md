# #76 选中另一座城时打开规划器，切到单城页（2026-10-25）

调研和方案在 #76 的评论里；维护者定方案 A，待定问题按建议（切到单城页时多城页的默认组仍以这座城为中心）。

## 做法

`SDP_Panel.lua` 的 `FollowSelection`（#63）在跟随了一座新选中的城时返回 true，`Open` 这时把页签设成单城再显示。条件和 #63 相同：

- 自上次打开以来，地图上选中了另一座本方城市：单城页换成这座城、多城页默认组以它为中心，面板打开在单城页；
- 没选城市，或选的还是上次那座：页签照旧是上次关面板时的；
- 后台还在计算：什么都不变（结果在原来的页签上）。

#57 记的是每个页签的设置，不记打开的页签；页签只在这一局界面里记着，读档后从单城页开始。

## 测试

- 离线：`spec_citychips.lua` 的跟随用例：同一座城仍选中时重开还是多城页；选了另一座城，打开在单城页、单城页面显示；什么都没选时重开还是选城址页；计算中选另一座城，页签不变。
- 游戏内真实点击：`realclick.py` 里选城、开面板的步骤（见 PR）。
