# #166 多城页的奇观设置记不住

## 原因

- #57 把每个页签的开关、权重、档位（后来加了收起与否）记进存档（`SDP_Settings`，存在本地玩家的 `PlayerConfiguration` 里），奇观没列进去。同一局里奇观一直留在面板的内存里（多城页 `m_wonders`、单城页 `m_wonders`），所以关面板、切页签都还在；读档后面板的 Lua 重新加载，奇观就没了。单城页也一样，不只是多城页。
- 读档后再打开“替换本模组之前的钉”（这个开关是记住的）：之前和奇观一起打过钉的城，奇观钉被当作要替换的钉（#154），奇观回到“可选”，但因为没记住、不在已选里，方案不规划它，打钉时它的旧钉又被删掉，奇观钉就丢了。#154 修的是同一局里的这条路；读档后靠这次的修复。
- 离线复现：`tests/offline/spec_wonder_memory.lua` 在旧代码上 4 项全失败（读档后多城页、单城页的奇观都是空的；选、去掉奇观不写进存档；打过钉的奇观不在存档里）。

## 修法

- `SDP_UI.WonderSetting(chosen)`（`SDP_Panel.lua`）：把一个页签已选的奇观作为 `WONDERS` 一项记住，类型按字母排序、逗号分隔（`list` 字段，`SDP_Settings` 只留匹配 `^[%w_]+$` 的项）；读回时只留这个规则集里 `IsWonder` 的建筑，原地改 `chosen`。
- 单城页、多城页的 keeper 各加这一项（`Extra`，不属于预设：换预设不动奇观，也不影响“自定义”的判断）。两页的 `SetWonder` 在选中状态变了时调 `Remember()`。
- 打过钉的奇观在内存里一直是已选，只是列表里暂时不显示；存档里也照样记着它，所以读档后和同一局里一样：开着“替换”时它重新规划（#154），关着时它留在原来的钉上。
- 不涉及求解和遍历顺序：存的是排序后的列表，读回只做查表。

## 第二句的理解

Issue 第二句“如果选了替换旧钉，只要奇观还未拍下，就依旧可以反复选择”：“拍下”按 #165 的用法理解为奇观已经开始建造（放到地图上）。开始建造后地块上就有这个奇观（`plot:GetWonderType()`，游戏的 `PlotToolTip.lua` 也这样区分在建与建成），`SDP_Wonders.Built` 算它已建，不再可选；在那之前，开着“替换”时它可以一次次重新规划，这是 #154 定下的行为，这次保持不变。在 Issue 上请合作者确认这个理解。
