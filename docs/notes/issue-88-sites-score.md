# #88 选城址计分：各项折成每回合点数（2026-10-26）

决定：[#88 合作者已定](https://github.com/SmallSpider0/civ6-smart-district-planner/issues/88)（方案 A），资源部分按 [#86](https://github.com/SmallSpider0/civ6-smart-district-planner/issues/86) 已定的公式，住房按 #91 的方案 B。

## 1. 公式

```
城址分 = 区域 + 地块 + 地貌 + 住房 + 奢侈 + 战略 + 魅力 − 可用格不足扣分
```

每一项都是“每回合相当于多少点产出”，再乘这一项自己的权重（页签上的区域、地块、地貌、住房、奢侈、战略、魅力，默认 1，魅力默认 0）。产出按地块的固定倍数折算（食物、生产力 1，科学、文化 5/6，信仰 1/2，金币 1/4，`SDP_Land.PLOT_WEIGHTS`），再乘页签上这种产出的权重。不按城址之间的差别归一化。

| 项 | 怎么算（代码） |
|---|---|
| 区域 | 计划区域在城址周围最好摆法的相邻加成（DMT），和单城页一样 1 点产出算 1 分，乘产出权重和区域权重（`SDP_Sites.Board` 的 `AdjacencyWeights`）。距离成本也在这里扣。 |
| 地块 | 区域占格后，最好 P 格每回合的产出（修上最好的改良）。每格按“留着”或“砍掉/收获后”取较好的那种的每回合产出；P = 3k − 2（`SDP_Sites.LandParts`、`SDP_Land.WorkedParts`）。 |
| 地貌 | 3 环内每格的砍伐、收获一次性产出 × 增长倍数 ÷ 50 回合，只算这格被砍掉/收获时：城市不耕作的格都算；耕作的格只在砍掉更值时算（`SDP_Land.PlotValues` 的第三个返回值是留着时放弃的那部分）。 |
| 住房 | 住房权重 × [HV(该城址住房) − HV(无水城址住房)]，HV 按 #91 方案 B（新城按人口 1）。 |
| 奢侈 | 新种类的第一份：min(资源的宜居度 4, 方案完成后的城市数)；其余份数每份 1，最多卖给“已相遇、还没有这种资源的主要文明”个数（玩家自己多出的份数先占）。 |
| 战略 | 每格 时代分 × 种类分。时代分：揭示科技在玩家所在时代或前一个时代为 2，更早为 1；种类分：新种类的第一格 2，已有但不够用（风云变幻：库存不到上限 25% 或每回合收入 ≤ 0）1.5，其余 1。 |
| 魅力 | 魅力权重 × 可建区域格的平均魅力（还没有折成每回合的说法，默认 0）。 |

- 地块 + 地貌 = 原来的“耕作 + 地貌”之和的同一种算法：每块耕作的格取 max(留着的每回合产出, 砍掉后的每回合产出 + 一次性产出 ÷ 50)，不耕作的格只算一次性那部分。拆开只是为了显示和分开加权。
- 一次性产出按 50 回合摊开（原来 20）。其他游戏速度：游戏把砍伐、收获的产出按速度放大，回合数按决定也按同样比例放大，两者抵消，所以代码里各速度都是 50。
- 一次性产出仍按科技市政进度增长：×(1 + 9 × 进度)，和单城页一样（`SDP_Land.ONE_TIME_GROWTH`）。
- 单城、多城页的地块模型不变（一次性产出仍按 20 回合）。
