# #49 玩法预设（2026-10-25）

调研、方案草稿和决定都在 #49 的评论里。决定（2026-10-25）：第一版预设是均衡（默认）、科技、宗教、金币信仰减半；文化看实验再定（实验后加上了）。去掉“工业与覆盖”和“保留地块”（覆盖权重、地块权重由玩家自己调）。预设只改权重和开关，不改预选的区域。侧重倍数按实验从 1.5、2、3 里选，去留规则照草稿。

## 预设

| 预设 | 改了什么（其余同均衡：产出权重 1，地块 1，距离 0，住房 1，覆盖 0，开关默认） |
|---|---|
| 均衡 | — |
| 科技 | 科学 1.5（`SDP_Settings.FOCUS.SCIENCE`） |
| 文化 | 文化 3（`FOCUS.CULTURE`） |
| 宗教 | 信仰 3（`FOCUS.RELIGION`）。#53 定了产出权重默认全 1，草稿里“先把信仰从 0.5 提到 1”不再需要 |
| 金币信仰减半 | 金币 0.5、信仰 0.5（购买价：1 生产力 = 4 金币 = 2 信仰），不需要实验 |

倍数由下一节的实验定。

## 实验

依据：评测基线（#48）的真最优测试集，只算相邻加成（地块部分不随产出权重变，见 #53）。

- 场景：开发集 72 个单城场景（`S`）；留出集（`HS`）只复核。
- 每个预设、每个候选倍数求真最优（全部证明）。均衡（全 1）、科学 3、信仰 3、金币信仰减半的真最优已在 #48 的 `w53_oracle.jsonl`（开发集）、`w53_oracle_hs.jsonl`（留出集）里；这次补科学、信仰、文化各 ×1.5、×2 和文化 ×3：
  ```
  node tools/compare.mjs -s '^S\d\d-[^~]*$' -p sdp --only sdp:ORACLE --add sdp:ORACLE --weights tests/compare/weights/w49.jsonl -j 4 --out tests/compare/results/w49_oracle.jsonl
  ```
  504 次，0 失败。
- 指标：用 #48 的 `robust53.py` 算（裁判的加成对权重是线性的，方案 A 在权重 B 下的分由它的分产出加成直接算出）：均衡的方案在预设下的损失（相对该预设的真最优）、均衡的方案在预设下也是最优的场景比例。
  ```
  python3 -I tests/compare/robust53.py --vectors <w53.jsonl 与 w49.jsonl 合并> tests/compare/results/w53_oracle.jsonl tests/compare/results/w49_oracle.jsonl
  ```
- 去留：均衡的方案在预设下平均损失 < 2% 且 ≥ 80% 的场景也是最优，算并入均衡；倍数取不并入的最小值。文化只在 ×3 也不并入时才加。

开发集结果（均衡的方案用在预设上）：

| 预设 | ×1.5 | ×2 | ×3 | 取 |
|---|---|---|---|---|
| 科技 | 损失 2.00%，44/72 最优 → 不并入 | 3.56%，43/72 | 6.43%，35/72 | 1.5 |
| 宗教（信仰） | 0.70%，60/72 → 并入 | 1.38%，59/72 → 并入 | 3.62%，49/72 → 不并入 | 3 |
| 文化 | 0.79%，58/72 → 并入 | 1.39%，58/72 → 并入 | 2.94%，46/72 → 不并入 | 3（加上文化预设） |
| 金币信仰减半 | — | — | — | 2.63%，47/72 → 不并入，保留 |

反过来，预设的方案用在均衡上的损失（选了预设而其实想要均衡时少拿多少）：科技 ×1.5 0.08%，文化 ×3 1.04%，宗教 ×3 1.72%，金币信仰减半 0.54%。

科技 ×1.5 的平均损失正好 2.00%，按“< 2%”算不满足；而且只有 44/72（61%）的场景均衡方案也是最优，远低于 80%，两条都不满足也不改结论。

留出集复核：科学 1.5、信仰 2 与 3、文化 2 与 3 在留出集 72 个场景上的真最优（360 次，全部证明，0 失败），均衡和金币信仰减半用 #48 的 `w53_oracle_hs.jsonl`：

```
node tools/compare.mjs -s '^HS\d\d-[^~]*$' -p sdp --only sdp:ORACLE --add sdp:ORACLE --weights tests/compare/weights/w49hs.jsonl -j 4 --out tests/compare/results/w49_oracle_hs.jsonl
python3 -I tests/compare/robust53.py --vectors <w53.jsonl 与 w49.jsonl 合并> tests/compare/results/w53_oracle_hs.jsonl tests/compare/results/w49_oracle_hs.jsonl
```

| 预设 | 留出集（均衡的方案用在预设上） | 结论 |
|---|---|---|
| 科技 ×1.5 | 损失 1.04%，54/72（75%）最优 → 不并入 | 同开发集 |
| 宗教 ×2 / ×3 | 1.24%、59/72 → 并入 / 3.86%、45/72 → 不并入 | 同开发集，取 3 |
| 文化 ×2 / ×3 | 1.55%、58/72 → 并入 / 3.39%、46/72 → 不并入 | 同开发集，取 3 |
| 金币信仰减半 | 1.83%，51/72（71%）→ 不并入 | 同开发集 |

科技 ×1.5 在留出集上离并入更近（损失低于 2%，只差在 80% 那一条）；按规则仍不并入。

## 界面

- 单城、多城页的权重标题行右侧：“预设”下拉框和“恢复”按钮。下拉框每项的悬停写改了什么（`LOC_SDP_PRESET_*_TOOLTIP`，倍数从 `FOCUS` 取）。选一个预设，把权重和开关都设成它的值（档位、设置区收起与否不变）；改过以后下拉框和设置摘要写“科技（已改）”，“恢复”按钮可点，点它回到预设的值。
- 存档里记预设名加改过的项（#57），以后版本调了预设的值，玩家没改过的项跟着变。
- 选城址页沿用它自己的三个预设（均衡、成长优先、区域优先），不变。

## 代码

`SDP_Settings.PRESETS`、`PRESET_ORDER`、`FOCUS`；`keeper.Use(name)`（把可由预设设置的项设成预设值）；`SDP_UI.ShowPreset`；单城 `SetPreset`，多城 `P.SetPreset`。
