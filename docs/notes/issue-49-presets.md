# #49 玩法预设（2026-10-25）

调研、方案草稿和决定都在 #49 的评论里。决定（2026-10-25）：第一版预设是均衡（默认）、科技、宗教、金币信仰减半；文化看实验再定。去掉“工业与覆盖”和“保留地块”（覆盖权重、地块权重由玩家自己调）。预设只改权重和开关，不改预选的区域。侧重倍数按实验从 1.5、2、3 里选，去留规则照草稿。

## 预设

| 预设 | 改了什么（其余同均衡：产出权重 1，地块 1，距离 0，住房 1，覆盖 0，开关默认） |
|---|---|
| 均衡 | — |
| 科技 | 科学 ×k（`SDP_Settings.FOCUS.SCIENCE`） |
| 宗教 | 信仰 ×k（`SDP_Settings.FOCUS.RELIGION`）。#53 定了产出权重默认全 1，草稿里“先把信仰从 0.5 提到 1”不再需要 |
| 金币信仰减半 | 金币 0.5、信仰 0.5（购买价：1 生产力 = 4 金币 = 2 信仰），不需要实验 |

**k 现在是占位值 2**，等预设倍数实验（下一节）定下后改 `SDP_Settings.FOCUS`，并把结果和命令记在这里。

## 实验（待做）

依据：评测基线（#48）的真最优测试集，等它就绪后做。

- 场景：开发集 `S`/`M`，留出集只复核；
- 每个候选 k ∈ {1.5, 2, 3}，对科技、宗教（以及文化）各求真最优；
- 指标：均衡的方案在该预设下的损失（平均 / 最大）、方案与均衡相同的场景比例；该预设的方案在均衡下的损失；
- 去留：均衡的方案在预设下平均损失 < 2% 且 ≥ 80% 的场景方案相同，算并入均衡；k 取不并入均衡的最小值。文化预设只在 k = 3 也不并入时加。

## 界面

- 单城、多城页的权重标题行右侧：“预设”下拉框和“恢复”按钮。下拉框每项的悬停写改了什么（`LOC_SDP_PRESET_*_TOOLTIP`，倍数从 `FOCUS` 取）。选一个预设，把权重和开关都设成它的值（档位、设置区收起与否不变）；改过以后下拉框和设置摘要写“科技（已改）”，“恢复”按钮可点，点它回到预设的值。
- 存档里记预设名加改过的项（#57），以后版本调了预设的值，玩家没改过的项跟着变。
- 选城址页沿用它自己的三个预设（均衡、成长优先、区域优先），不变。

## 代码

`SDP_Settings.PRESETS`、`PRESET_ORDER`、`FOCUS`；`keeper.Use(name)`（把可由预设设置的项设成预设值）；`SDP_UI.ShowPreset`；单城 `SetPreset`，多城 `P.SetPreset`。

## 测试

离线 `spec_panel.lua` 的 “issue 49”：经下拉框条目选科技，权重变化，存档里只记预设名；改一项后显示“（已改）”、摘要行同样；点“恢复”回到预设；多城页的预设与单城页分开。
