# #71 窗口按屏幕高度、设置区折叠、看地图、方案一行、区域数量默认 3（2026-10-25）

调研在 #67 的评论里（M1–M4、S1(b)），维护者 2026-10-25 定：区域数量默认 3，M1–M4 照建议做，权重行标题从 #67 移到这里。

## 做了什么

| 项 | 改动 | 代码 |
|---|---|---|
| 区域数量默认 3 | `SDP_UI.ListRequest` 的 count 为 nil 时用 `SDP_UI.DEFAULT_COUNT`（3），单城 `m_count`、多城每份清单的 `Count` 默认都是 nil。必建多于 3 个时等于必建个数（原有规则）。多城页套用模板只换区域，保留清单原来的数量（原来会把数量清成默认） | `SDP_Panel.lua`、`SDP_PageMulti.P.ApplyPlan` |
| M1 窗口高度 | 窗口高 = 屏高 − 85（阴影偏移 60 加阴影边 25）− 35（阴影边 25 加 10），至少 640；三个页面 = 窗口高 − 100。打开时（`OnInit`、`LoadScreenClose`）和 `SystemUpdateUI.ScreenResize` 时重算。1080 的屏是 960（原来固定 920） | `SDP_UI.WindowHeight`、`FitWindow` |
| M1 结果列表 | 每次显示结果、折叠、换屏高后，结果列表取页面剩下的高度，至少 40（一行）（`SDP_UI.FitResults`）。多城页原来的 `FitPage`（结果列表 96、缩到 80、再缩城市格子、最后 40）改成：先按剩下的高度给结果列表，不到两行（80）时城市格子从 5 行往 2 行缩 | `SDP_UI.FitResults`、三个页签的 `FitPage` |
| M2 折叠 | 每个页签加一行摘要按钮（`FoldButton` 等）：写预设名（改过权重或开关时加“（已改）”，`SDP_Settings.Changed`）和不同于平常的设置（不计占地、不砍伐、换格、替换旧钉、奇观个数、好位置）。下面的奇观、好位置、权重、开关（选城址页：预设和权重）放进一个 Stack，求解时收起，点摘要切换。收起与否按 #57 记进存档（`FOLD`） | `SDP_UI.ShowFold`、`SDP_UI.FoldSummary`、`UpdateFold`、`SetFold` |
| M3 看地图 | 标题栏左侧加“看地图”：隐藏窗口（`DropShadow`），面板仍在弹窗队列里，所以地图预览留着；左上原窗口位置出现“返回规划器”（`PeekReturn`），点它或按 Esc 回来。上下文一直显示（坑 23）；关面板时结束看地图 | `SetPeek`、`OnInput` |
| M4 方案一行 | `SolutionRow` 改成 156 宽的按钮，三套方案在 `SolutionStack` 里横排（StackGrowth Right）；挑出的区域放进按钮的悬停提示 | `SDP_UI.SolutionRow`、`SDP_Panel.xml` |
| 权重标题 | 权重行上加一行标签“权重（0–3）”，悬停说明产出权重和“地块”列。单城、多城页权重行 9 列×50 = 450，放不下左侧标题，所以单独一行（设置区能收起后，多这一行不挤按钮）；选城址页两行各 6 列×60，标题放在左侧 | `SDP_Panel.xml` |

## 没做

- B1（低分辨率下按钮落到屏幕外）没请合作者在 Windows 上确认。窗口最低 640；屏幕低于约 760 时，设置区展开的单城页仍可能超出窗口，收起后能放下（离线没有真实尺寸，要在游戏里截图看）。
- 低屏上自动收起设置区：没做。展开是玩家点的，再自动收起会让人点不开；求解后本来就收起。

## 测试

- 离线 `spec_panel.lua` 的 “issue 71” 四项：屏高到窗口高的换算和 `ScreenResize`；结果列表撑满且不少于一行；求解后收起、点摘要展开、存档里的 `FOLD`；三个页签都能收起；看地图后窗口隐藏、预览不清、上下文仍显示，按钮和 Esc 都能回来，关面板时结束；方案按钮的悬停提示是挑出的区域，点一个选中它。区域数量默认 3 在 “district states and the count” 和多城第一项里查。
- 游戏内：真实点击（摘要行、看地图和返回、方案按钮），中英截图看三个页签的布局，1080 和更低的窗口化分辨率各看一次。
