## 验收清单（需求文档第五节）

| # | 验收项 | 结论 | 证据 |
|---|--------|------|------|
| 1 | 模组列表正确显示中文名与描述 | 自动验证（Lua）+ 截图 | 主菜单状态下，列表用的 `Locale.Lookup(Name)` 与详情用的 `Modding.GetModText` 均返回"智能区域规划器"及中文描述。modinfo 内嵌 `<LocalizedText>`，未启用时也能显示。额外内容界面未能截到本模组那一行（列表需滚动，无法合成点击）。额外内容界面的截图见下 |
| 2 | 启动栏出现图标按钮，点击弹出面板 | 自动验证 + 截图 + 真实鼠标点击（macOS） | `test_panel`：按钮注入、弹窗队列开关、Esc 处理、LuaEvents 开关。截图见下。第六轮起用系统鼠标事件真实点击面板（`tools/realclick.py`，30 项通过，见下）；启动栏按钮本身与 Esc 键仍由测试调用 |
| 3 | 学院+圣地秒级出结果；互惠更优解必须给出 | 自动验证 | `test_solver`：两区域走穷举，结果与 DMT 暴力枚举的最优提升完全相等（全 1 权重与只看科学权重各一次）。耗时见"性能"一节 |
| 4 | 结果行显示坐标与明细；悬停逐项来源与 DMT 图钉一致 | 自动验证 + 截图 | `test_ui`：结果行含坐标，tooltip 等于方案中 DMT 的 tooltip。`test_pins`：打钉后 DMT 为每个钉保存的 tooltip 与方案逐字相同。悬停截图见下 |
| 5 | 打钉生成带区域图标的钉；撤销后新钉被真删除 | 自动验证 + 截图 | `test_pins`：钉图标为 `ICON_<区域>`；撤销后钉从 `GetMapPins()` 消失，DMT 记录清空，玩家自己的钉保留。地图截图见下；撤销后截图中钉全部消失 |
| 6 | 已建区域置灰且不可勾选 | 自动验证 + 截图 | `test_built`：用游戏核心 API 建好学院后，面板里学院格状态为"已建"、变暗且不能点；求解时学院列为未放置（BUILT），已建学院作为固定邻居计分 |
| 7 | 同一状态求解两次结果一致 | 自动验证 | `test_solver`、`test_overlay`、`test_city`、`test_rules` 各有"重复两次深比较相等"的用例。求解器只遍历排序数组，预算按计数，不用随机数和时间 |
| 8 | 勾 3–4 个区域不卡死（≤ ~2 秒） | 自动验证 | `test_solver_perf3/4/8` 设有 2.5 秒墙钟上限，实测远低于上限。第二轮：快速、标准档同步求解，8 个区域 ≤ 0.3 秒；精细档、多城、城址分帧计算，计算期间游戏照常响应（见"性能与单价"） |

## 开发中发现并已处理的问题

| 问题 | 处理 |
|------|------|
| DMT 在未揭示格子上调用 `CanPlacePin` 会报错 | 扫描时排除未揭示格；overlay 把单项错误记为不可放置，不中断整次求解 |
| DMT 的地块特征缓存只按坐标做键，结果会受调用顺序影响 | overlay 每次改动层前后都清缓存（`UpdatePinYields(pid, {})`） |
| 新建地图钉后，之前取到的钉对象失效，调用其方法使游戏崩溃（SIGSEGV） | 只保存钉 ID，每次用 `GetMapPinID` 重新取（AGENTS 坑 21） |
| `GetMapPin(x, y)` 会在空格子上新建钉 | 查找改为遍历 `GetMapPins()`（AGENTS 坑 22） |
| luaparse 的 5.1 模式会误报合法的 `break;` | 改用 5.3 模式解析，再用规则禁掉 5.1 没有的语法 |

| `ICON_YIELD_*_1` 图标缩小后只剩小点 | 权重图标改用城邦使者加成图标，并着深色 |
| 随机开局可能是海上开局（毛利），第 1 回合无法建城 | 测试对局固定领袖和种子 |
