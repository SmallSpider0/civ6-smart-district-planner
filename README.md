# Smart District Planner（智能区域规划器）

《文明6》纯 Lua UI Mod：为单个城市穷举 3 环内的区域摆放，按玩家可调的分类型权重求出相邻加成最大的方案，并一键生成带区域图标的地图钉。依赖 Detailed Map Tacks（DMT）。

- 需求：[civ6-mod-from-scratch-prompt.md](civ6-mod-from-scratch-prompt.md)
- 开发约定：[AGENTS.md](AGENTS.md)
- 设计说明：[docs/design.md](docs/design.md)
- 安装与测试：[docs/install-and-test.md](docs/install-and-test.md)
